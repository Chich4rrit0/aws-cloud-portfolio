# Cost Check — Phase 2: Local API Foundation

**Date:** 2026-09-06
**Scope:** Node.js API, Express, automated tests, and local development server.

## Resources created

- Local source code and npm dependencies only.
- No AWS resources.

## Resources that generate cost

- None.

## Resources that can be stopped or deleted

- The local development server can be stopped at any time with `Ctrl+C` when it is running in an interactive terminal.
- `node_modules` can be recreated with `npm install`; it is intentionally ignored by Git.

## Unexpected-cost risk

- None in AWS for this phase.
- Future phases must not introduce AWS resources without an explicit plan, estimated cost, and approval.
